# AI marker 제거 스킬

경력기술서/자기소개서처럼 실제 이력서에 들어갈 글에서, AI가 작성했다는 흔적(AI marker)을
제거해 사람이 직접 쓴 것처럼 자연스럽게 만드는 스킬입니다. 이력서에 AI 흔적이 남아있으면
채용 담당자나 AI 탐지 도구에 걸릴 수 있으므로, 대상 문서는 항상 꼼꼼히 검수합니다.

## 절차

1. **대상 파일 확인**: 사용자가 지정한 파일(들)을 읽는다. 지정하지 않았다면 저장소에서
   이력서/자기소개서/경력기술서로 보이는 파일(예: `*resume*`, `*자소서*`, `*cover*`,
   `*introduction*`, `*.md`, `*.docx`, `*.txt`)을 찾아 사용자에게 확인한다.

2. **기계적 정리 먼저 실행**: 보이지 않는 워터마크/특수 문자는 판단 없이 바로 제거 가능하므로
   스크립트로 먼저 처리한다.

   ```bash
   python3 .claude/skills/remove-ai-markers/scripts/strip_invisible_chars.py <파일경로>
   ```

   결과를 확인한 뒤, 실제로 파일을 덮어쓰려면 `--write` 옵션을 추가해서 다시 실행한다.
   (사용자 승인 없이 임의로 원본을 덮어쓰지 말고, 무엇을 지웠는지 먼저 보고한다.)

3. **문체 검수**: `references/ai_tells_ko.md`에 정리된 체크리스트를 기준으로 본문을 문단
   단위로 읽으며 다음을 찾는다.
   - 상투적 접속/전환 표현("또한", "결론적으로", "다시 말해" 등)의 기계적 반복
   - 클리셰 형용사("탁월한", "혁신적인", "열정적으로" 등)와 근거 없는 자기평가
   - "첫째/둘째/셋째"처럼 지나치게 균등하고 정형화된 나열 구조
   - 구체적 수치·프로젝트명·기간이 빠진 뭉뚱그린 성과 문장
   - AI 응답에서 실수로 남은 안내성 문구("다음은 ~입니다:" 등)
   - 문장 시작 패턴이 반복되거나 문단 길이가 부자연스럽게 대칭적인 경우

4. **재작성**: 찾은 항목은 다음 원칙으로 고친다.
   - 클리셰는 삭제하거나 실제 경험에서 나온 단어로 교체한다.
   - 근거 없는 주장은 구체적인 수치·기간·역할로 채운다. 사용자가 제공한 정보가 없으면
     지어내지 말고 사용자에게 되물어 구체적인 사실을 받아온다.
   - 문장 길이와 시작 방식에 변주를 줘 리듬을 자연스럽게 만든다.
   - 지원자의 원래 어조와 1인칭 시점은 유지한다 — 내용을 과장하거나 새로 지어내지 않는다.

5. **보고**: 무엇을 왜 고쳤는지 간단히 요약하고, 특히 "이 부분은 구체적인 사실이 필요합니다"
   처럼 사용자 확인이 필요한 부분은 명확히 표시한다.

## 주의사항

- 이 스킬은 표현/문체를 다듬는 것이지, 경력이나 사실 관계를 새로 지어내는 것이 아니다.
  실제로 없었던 성과나 수치를 만들어내지 않는다.
- 원본 파일을 덮어쓰기 전에는 항상 변경 내용을 사용자에게 보여주고 확인받는다.
