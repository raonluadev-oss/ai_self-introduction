# ai_self-introduction

## ai-marker-remover 플러그인

작성된 글(자기소개서 등)에서 다음 세 가지를 찾아 제거하고 자연스럽게 다듬어주는 Claude Code 플러그인입니다.

1. **AI스러운 표현/문체** — 상투적인 전환구, 부자연스러운 em dash 남용, 과도하게 정형화된 구조 등
2. **눈에 보이지 않는 워터마크 문자** — zero-width space, 유니코드 태그 문자, Variation Selectors Supplement 등 텍스트에 숨겨진 문자
3. **AI 생성 메타데이터·서식 흔적** — "Generated by ...", 숨겨진 주석, 복사 과정에서 섞여 들어간 불필요한 서식

### 로컬에서 사용해보기

```bash
claude --plugin-dir .
```

Claude Code 세션에서:

```
/ai-marker-remover:ai-marker-remover
```

또는 그냥 "이 글에서 AI 마커 지워줘" 라고 요청하면 설명(description)에 따라 자동으로 트리거됩니다.

### 상시 설치

`.claude/settings.json`에 다음을 추가하면 이 저장소를 플러그인 디렉터리로 계속 사용할 수 있습니다.

```json
{
  "enabledPlugins": ["ai-marker-remover@<이 저장소 경로 또는 마켓플레이스 이름>"]
}
```
